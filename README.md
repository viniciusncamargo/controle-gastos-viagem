# controle-gastos-viagem
App para controlar gastos de viagem em diversas moedas, convertendo-os para Real
Projeto de estudo.

## Funcionalidades do MVP
- Entrar com a conta Google
- Criar, listar, editar e apagar viagens
- Anotar gastos em qualquer moeda
- Ver cada gasto e o total da viagem convertidos para reais
- Definir um orçamento para a viagem

## Tecnologias
- React (interface)
- Firebase (login, banco de dados e hospedagem)
- AwesomeAPI (cotação das moedas)
